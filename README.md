# 热穿透放行复核台（Heat-Penetration Review Console）

浏览器端多通道时间-温度数据的 F0（致死率）复核工作台：导入本釜各通道数据后，
在**真实时间轴**上做线性插值与致死率积分，拆分升温 / 保温 / 降温贡献，自动识别
本批冷点；对时间倒退、长缺口、探针漂移、阶段覆盖不完整等问题**阻止受影响结论**
（不补零、不沿用上一温度），并以候选方式提供校时 / 停用探针的影子比较，采用后
可撤销重做，全部状态本地保存。

> **重要声明：本工具仅用于工程复核与证据留痕，不替代适用法规（如 21 CFR 113/114、
> GB 4789 等低酸性罐头杀菌规程）规定的杀菌工艺判定与授权人员放行。任何“可放行”
> 显示都不构成法规意义上的放行结论。**

## 功能

- **多通道导入**：CSV（首行表头，首列时间，其余每列一个通道；表头含“釜/retort”
  识别为釜温）。时间支持秒、`mm:ss`、`hh:mm:ss` 与 ISO；空单元为缺测。
  首屏内置 1 路釜温 + 6 支探针示例（含短缺测与疑似漂移）。
- **致死率数学**：瞬时致死率 L(T)=10^((T−Tref)/z)，min⁻¹；温度沿相邻有效读数
  **线性变化**时采用解析积分 `L1·Δt·(r−1)/ln r`（等温退化为 L1·Δt），
  采样间隔不规则不影响结果。
- **阶段归因**：按保温开始 / 结束边界，分别给出升温、保温、降温 F0 贡献，
  三段之和恒等于全过程累计值；支持按釜温自动识别保温段。
- **门禁（关键安全语义）**：
  - 缺测区间不构造任何线段——**绝不补零、绝不 hold-last**；
  - 跨过缺测的两端读数间隔 ≤ 允许缺测时长才允许线性插值，并留 `warn` 证据；
  - 超过允许时长 → `block`，缺口区间不积分，纹理显示在曲线上；
  - 时间戳倒退（非单调）→ 不重排、不掩盖，该通道 `block`；
  - 探针对任一阶段起点/终点覆盖不完整 → 该阶段与该探针 `block`；
  - 保温中段相对其余探针中位温度持续偏差超过漂移阈值 → `block`（接近阈值时 `warn`）；
  - 未设定保温阶段 → 全批结论阻止。
- **冷点**：在通过全部门禁的有效探针中，取全过程累计 F0 最低者；任何探针失效
  都会重选冷点并使结论悬置，直到证据被处理。
- **首屏联动**：过程温度曲线 + 累计 F0 曲线（目标线、阶段带、缺口纹理）、
  探针排行（分阶段贡献、冷点标记）、偏差证据、十字游标（各通道温度 / 瞬时 L /
  累计 F0 的 tooltip 与表格）。
- **候选比较**：校时建议（探针升温曲线相对其余探针整体平移的最小误差对齐）与
  停用 / 启用探针都先做**影子分析**，与现状并列对比后才可“采用”；原始数据永不
  被改写，调整只存在于调整层。
- **历史与本地保存**：采用、参数修改、导入都进入撤销 / 重做栈（最多 50 步）；
  数据集、参数、调整与完整历史持久化在 `localStorage`，刷新后恢复且仍可撤销。

## 判定含义

| 结论 | 含义 |
|---|---|
| **可放行**（绿） | 全部参与判定探针通过门禁，且冷点累计 F0 ≥ 目标 F0。仍需人工法规签署。 |
| **F0 不足**（红） | 数据有效，但冷点累计 F0 < 目标 F0；杀菌强度客观不足。 |
| **结论悬置**（橙） | 存在 block 级证据或无有效探针：不得放行，先处理证据（校时/停用候选或重新采集）。 |

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # vitest，全部领域与界面测试
npm run build      # tsc 类型检查 + vite 生产构建
npm run preview    # 预览构建产物
```

技术栈：React 18 + TypeScript（strict）+ Vite 5 + Vitest（jsdom）+ Testing Library。
无第三方图表库，图表为手写 SVG（2px 线、十字游标、surface 色环的可视化规范）。

### 测试覆盖（41 个用例）

- **不规则积分**：解析解 vs 20 万段梯形数值解；不规则/规则采样同过程 F0 一致；
  恒温 F0 精确；短缺口插值与累计单调性。
- **阶段边界**：三段之和=总数、边界不重不漏、未设/反设阶段被阻止。
- **缺口门禁**：保温长缺口不积分且结论悬置；缺口宽度证据；短缺口仅 warn；
  时间倒退 block；提前结束 / 迟到的覆盖阻止。
- **冷点**：有效探针最低 F0；失效后重选；全部失效无冷点；停用不参与判定。
- **漂移候选**：超阈值 block；阈值 60–100% 仅 warn；停用影子比较→采用→撤销；
  时钟错位证据与校时候选；原始数据不被改写。
- **历史恢复**：撤销/重做、重做分支失效、localStorage 往返（含历史栈）、
  损坏存储安全忽略；界面冒烟（示例首屏、采用候选、撤销、免责声明）。

## 再次提醒

本台输出的 F0、冷点与“可放行”状态是**工程复核信息**。放行 authority 在法规
与工厂质量体系；对偏差证据的“停用探针”属于人工工程决定，必须按偏差处理程序
留档，不能用本工具的撤销/重做替代正式记录。
