# 热穿透放行复核台（Heat-Penetration Release Review Console）

浏览器端的多通道热穿透数据复核工具：导入釜温与多支罐内探针的时间-温度数据，
在**真实时间轴**上插值积分致死率，分阶段统计 F0 贡献，自动找出本批冷点，
并对时间倒退、长缺口、探针漂移/卡死、阶段覆盖不完整等问题**阻断受影响结论**。

> **免责声明：本工具不替代法规放行。**
> 它只是工程复核与教学辅助，按用户提供的数据与参数机械计算，不验证传感器是否经校准、
> 取样方案是否合规、釜内分布是否被代表性覆盖。任何批次的正式放行必须依据适用法规
> （如 GB 4789 系列、21 CFR Part 113/114 等）规定的杀菌规程、记录、偏差处置程序，
> 由具备资质的人员签署。工具给出的"通过/条件通过"不是放行决定；"阻断/不予放行"时
> 必须按企业 HACCP/食品安全管理体系走偏差流程。

## 快速开始

```bash
npm install
npm run dev      # 本地开发
npm test         # 运行测试（vitest）
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

打开后自动载入内置示例批（1 路釜温 + 6 支探针），全部计算在浏览器本地完成，
数据不上传任何服务器，并通过 `localStorage` 自动保存刷新可恢复。

## 计算口径

- 瞬时致死率：`L(T) = 10^((T − Tref)/z)`（min⁻¹），默认 Tref = 121.1 ℃、z = 10 ℃。
- 累计 F0：`F = ∫ L(T(t)) dt`，**dt 以分钟计**。
- 温度在相邻**真实采样**之间按真实时间线性插值（采样不等间隔时区间长度按实际秒数）。
- 单区间积分使用指数函数的**对数平均致死率精确积分**
  `∫₀¹ 10^(a+(b−a)u)du = (10^b − 10^a)/((b−a)·ln10)`，
  而不是对端点致死率做梯形近似——指数曲线下梯形法会系统高估，
  且疏密不同的不规则采样会得到不同结果；精确积分没有这两个问题（有测试锁定）。
- F0 分别按**升温 / 保温 / 降温**三段累计，界面排行用堆叠条展示三段构成。

## 门禁规则（核心安全逻辑）

工具宁可不出结论，也不猜测温度：

| 情况 | 处理 |
|---|---|
| 时间戳倒退 | 该通道**阻断**，不做排序掩盖 |
| 同一时间戳两个温度 | 该通道阻断 |
| 缺测跨度 > 允许缺测（默认 90 s） | 长缺口：所在阶段标记**不完整**，该探针总 F0 **不出数**，不参与冷点 |
| 缺测跨度在允许内 | 警告并按真实时间轴线性插值（图表缺测轨道标黄） |
| 首/末采样未覆盖工艺窗口 | 阻断（阶段覆盖不完整） |
| 保温段温度同时持续高于釜温且高于同伴（默认 ≥2 ℃） | 判疑似正漂移，阻断该探针 |
| 升温段罐内温度持续高于釜温 | 物理不可能，阻断 |
| 保温段恒定而同伴随釜温波动，或降温时无响应 | 判卡死，阻断 |
| 阶段定义缺失/重叠/有缝隙/缺段 | 整批不出结论 |

**绝不补零，绝不沿用上一温度，绝不外推。** 长缺口在温度曲线与累计 F0 曲线上都
断开显示，累计曲线在缺口后不以"前段累计 + 猜测"冒充总量。

## 冷点与结论

- 冷点 = **有效探针中**累计 F0 最低者；被阻断的探针不参评。
- 结论分四档：
  - **通过**：所有探针有效、冷点 F0 ≥ 目标值；
  - **条件通过**：冷点达标，但存在允许内缺测等警告项，须人工确认；
  - **不予放行 (hold)**：数据完整但冷点 F0 低于目标；
  - **阻断 (block)**：存在数据缺陷、覆盖不完整或釜温通道异常——不能据此放行。
- 釜温通道本身有阻断缺陷时，无法确认工艺实际执行，整批阻断。

## 校时 / 停用候选（先比较，后采用，可撤销）

异常探针的处置不会自动生效：

- **校时候选**：比较各探针在升温跨 75/85/95 ℃ 与降温跨 115/110/105 ℃ 的时刻
  相对同伴中位数的偏移。整体时钟错位在**两个方向上偏移一致**；
  单纯的罐位热惯性（升温/冷却时间常数不同）两方向会发散，据此区分。
- **停用候选**：存在阻断性缺陷（漂移、卡死、长缺口等）的探针可停用比较，
  但停用意味着该罐位**失去本批验证**——候选比较不会增加安全裕度。
- 点"作为候选比较"只显示当前 vs 候选的对照表；"采用并刷新"才写入，
  且进入撤销栈，可逐项撤销或 Ctrl+Z / Ctrl+Shift+Z 撤销重做。

## 界面

- 顶部：结论横幅、冷点 F0 / 有效探针数 / 阻断缺口数 / 釜温保温均值等概览。
- 主图（双联、共享真实时间轴）：
  上半部分为温度曲线（釜温用虚线、探针按固定分类色、Tref 参考线、阶段带），
  下半部分为各探针累计 F0 与目标线；温度与累计曲线上的长缺口均断开。
  两面板之间的"缺测"轨道逐通道标注黄（允许内）/红（阻断）缺口。
- **游标**：在图上移动即显示各通道当前温度、瞬时致死率 L、截至该时刻累计 F0
  （缺测区间标注且不计）。
- 右侧：探针 F0 排行（冷点标记、三段贡献堆叠条）、候选与采用记录、
  偏差证据列表（阻断/警告分级）、工艺参数与阶段编辑。
- 支持浅色/深色主题，两套分类配色均通过色盲安全与对比度校验。

## 数据导入格式

宽表 CSV，首行表头，第一列为时间，其余每列一个通道：

```csv
time,釜温RT,P1,P2
0,35.0,35.1,35.0
0:15,41.2,,35.6
0:30,55.3,44.8,38.2
```

- 时间支持秒数（`4500`）、`mm:ss`、`hh:mm:ss`；
- 列名含"釜温/retort/rt"（不分大小写）的通道识别为釜温，其余为探针；
- **空单元格即掉线时刻，不产生采样**，相邻真实采样的时间差决定缺口长度；
- 阶段在导入时按 1/3、1/2、1/6 占位生成，**必须按实际工艺核对修改**后再看结论。

## 内置示例

`src/lib/sample.ts` 生成 75 min 工艺（15 min 升温 / 40 min 保温 / 20 min 降温）：

- P1–P4：热惯性递增的正常探针；
- **P3**：时钟整体错位 +60 s（两端各延伸采样保持窗口覆盖）→ 产生校时候选；
- **P5**：升温段 90 s 短缺测（恰为允许上限）→ 警告，条件通过；
- **P6**：快热罐位但保温段读数系统性偏高（高于釜温与同伴）→ 漂移阻断 → 停用候选。

```
src/lib/analyze.test.ts — 不规则积分一致性、对数平均精度、阶段边界、
                         缺口/时间倒退门禁、冷点、漂移与卡死、校时/停用候选、

```

关键不变量：任何阻断条件下受影响探针 `totalF === null` 且 `valid === false`，
冷点永远不会取到无效探针。

## 技术栈

React 18 + TypeScript（strict）+ Vite 5 + Vitest，无第三方图表/状态库，
图表为手写 SVG；状态为函数式撤销栈 + `localStorage` 持久化。
